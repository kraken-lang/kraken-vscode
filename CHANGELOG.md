# Change Log

All notable changes to the Kraken Language extension will be documented in this file.

## [0.1.0] - 2024-11-20

### Added
- Initial release
- Syntax highlighting for `.kr` and `.krak` files
- Support for keywords: `fn`, `let`, `mut`, `if`, `else`, `while`, `for`, `match`, `struct`, `class`, `interface`, `async`, `await`
- Support for types: `int`, `float`, `bool`, `string`, `void`
- Comment support (line `//` and block `/* */`)
- String literal highlighting with escape sequences
- Number literal highlighting (decimal, hex, binary, octal, float)
- Operator highlighting
- Function name highlighting
- Auto-closing brackets, quotes, and parentheses
- Code snippets for common patterns
- Proper indentation rules
- Bracket matching and folding
